slmeteo.plots.SkewT

class slmeteo.plots.SkewT

This class draws skewed humidity and dry and moist adiabats as baselines for a Skew-T log-p diagram. A user can plot a radiosonde on top of the baselines. The radiosonde is skewed as well before being drawn on the skew-T diagram. :meta hide-value:
