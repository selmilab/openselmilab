slmeteo.io module

slmeteo.io.uow_radiosonde(station_id, day, hour, format='dataframe')

This function builds the url and send the request for a radiosonde to the University of Wyoming Atmospheric Science Radiosonde Archive. The input parameters are:

  1. station id, a number

  2. the day of the radiosonde in the yyyy-mm-dd format

  3. the launch hour (e.g. 0 for midnight and 12 for midday)

Depending on the requested format the result can be a Pandas dataframe containing the full dataset or an ordered list of NumPy arrays for pressure (Pa), temperature (K), dew point (K), mixing ratio (g/kg)

slmeteo.thermodynamics.moist_adiabat(pressure_levels, T_i)

This function computes the moist (saturated) pseudo-adiabat starting from the input temperature (Kelvin). The input temperature is a scalar value. The returned values are in Kelvin. The calculation of the moist adiabats is more precise as the smaller is the delta between two pressure levels or, in other words, the more levels are used for the computation between the ground and the top level pressure.

slmeteo.thermodynamics.moist_adiabat_lapse_rate(p, T)

This function calculates the moist adiabatic lapse rate from pressure and temperature. The input temperature is in K and the input pressure is in Pa. The return value is in K/Pa

This function calculates the moist adiabatic lapse rate taking into account that the specific heat at constant pressure depends on the water vapor mixing ratio (Stull ch.3. eq. 3.3)
